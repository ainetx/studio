# Deprecated Deep Review Methodology Index

This compatibility file is not loaded or used by `cf-deep-review` version 0.4 and later.

Deep Review no longer performs automatic project discovery, methodology indexing, search-engine indexing, or catalog generation. Review coverage is assembled interactively from:

- checks proposed from target metadata and the current diff;
- checks authored by the user;
- checklist/reference files explicitly supplied by the user.

Do not invoke this module as runtime instructions. Existing user cache indexes are legacy artifacts and are not read or deleted automatically.
